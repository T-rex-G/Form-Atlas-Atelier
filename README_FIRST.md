## Preview without the noise

Nothing autoplays in the grid. Open a reference, then press Play preview for a real local clip, or Live preview for an interactive bundled code demo. Closing or switching references unloads the player and live demo. Preferences can opt into selected-reference playback; reduced-motion settings are respected.

Full image opens the native-resolution still, including the complete long page when available. These are real source images, actual source-animation frames, or genuine rendered publisher previews—not invented illustrations. New MP4s are silent H.264 excerpts up to eight seconds, at up to 960 pixels wide without upscaling. Retained older source footage can be smaller and is labeled separately. A publisher's current revision may differ from an archived prompt.

Copy prompt and Copy code copy complete text; the Code tab includes the MIT notice. If the clipboard is denied, the full exact text is shown for manual copying. Save .md / source file is also available. Bookmarks, notes and personal references persist in the browser when its storage is available; export your personal references regularly.

## Phone and laptop

The interactive app was tested offline in desktop Chromium at 1536×1024 and at 390×844 and 320×844 phone-sized viewports. Native clipboard and personal storage/export were additionally tested on localhost. Actual iPhone Safari, Files and Quick Look were not available for testing.

On iPhone, use an HTML viewer that runs JavaScript and can access the entire extracted folder. Files / Quick Look may not run the interactive app or allow sibling media. `VIDEO_GALLERY.html` provides native video controls without JavaScript. `PHONE_VIDEO_CHECK.html` tests one embedded clip; MP4s can also be opened directly from VIDEO.

If local-file restrictions prevent the app from working in your browser, run `python3 serve.py` on a computer from this extracted folder, then open http://127.0.0.1:8765. It binds to your computer only and uploads nothing.
